What this demo is doing

It reproduces scikit-learn’s lowercase TF‑IDF n-gram weighting and cosine ranking in the browser using the repository’s synthetic FAQ bank. It returns stored text; it does not generate answers.

Similarity is not calibrated confidence. The examples are invented and are not official guidance for a real campus.
